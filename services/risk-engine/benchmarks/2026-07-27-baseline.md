# Processing baseline — 2026-07-27

Command:

```sh
cargo run --release --bin risk-benchmark
```

This is an end-to-end processing measurement from normalized `PriceUpdate` entry through
preflight, incremental contribution calculation, account health and policy evaluation,
changed-state collection, and completion of every affected shard.

The measured P99 is below the Phase 0.1 target of 250 ms on this machine. Allocation figures are
cumulative across 200 iterations and include changed-state event buffers and scoped worker
orchestration. There is no allocation per evaluated exposure or unchanged account. This baseline
does not establish production behavior under concurrent system load.

## Configuration and machine

- CPU: AMD Ryzen 9 3900, 12 physical cores, 24 logical CPUs, SMT enabled
- NUMA: one node, CPUs 0–23
- Memory: 125 GiB
- Rust: `rustc 1.91.1 (ed61e7d7e 2025-11-07)`
- Target: `x86_64-unknown-linux-gnu`
- Profile: release, thin LTO, one codegen unit
- Exposure batch: one pre-partitioned contiguous asset range per affected shard
- Queue: not applicable in this in-process scoped-worker implementation
- CPU affinity: operating-system default
