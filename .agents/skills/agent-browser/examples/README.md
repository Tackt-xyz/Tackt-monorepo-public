# Examples for agent-browser

Quick reference for common browser automation tasks.

## Available Examples

| Example | Description |
|---------|-------------|
| [browse-and-summarize.md](browse-and-summarize.md) | Navigate to a page and extract/summarize content |
| [fill-form.md](fill-form.md) | Fill and submit web forms |
| [screenshot-workflow.md](screenshot-workflow.md) | Capture screenshots for documentation |
| [auth-and-scrape.md](auth-and-scrape.md) | Login and scrape protected content |

## Quick Prompts

### Research a Topic
```
Use agent-browser to open [URL], read the main content, and summarize the key points.
```

### Fill a Form
```
Use agent-browser to fill out the form at [URL] with this data: [field: value, ...]
```

### Take Documentation Screenshots
```
Use agent-browser to take screenshots of [feature] on [URL] for our documentation.
```

### Test a User Flow
```
Use agent-browser to test the signup flow on [URL] - create an account and verify success.
```

### Extract Structured Data
```
Use agent-browser to go to [URL] and extract all [items] into a JSON array.
```
